# 百度贴吧去广告 · Loon

基于 2026-10-27 的 iPhone 贴吧抓包编写。**当前版本 v0.2**：清除推荐接口内的完整广告卡片，同时修改首页、帖子横幅和评论区的广告配置，减少只去掉图片后仍保留卡片与空白的情况。

**当前状态：用户已确认 v0.1 开屏广告消失。v0.2 整卡和广告位处理已通过离线测试，等待用户真机复测；不能承诺全部去广告或所有留白消失。**

## 从 v0.1 更新

1. 在 Loon 更新本插件，确认描述显示 **v0.2**，并刷新两个远程脚本。
2. 新脚本地址带 `?v=20261027-2`，用于区分旧缓存；订阅地址不变。
3. 从后台彻底退出贴吧再重新打开，让 `/c/s/sync` 重新同步配置；进入首页后下拉刷新，再打开一个帖子。
4. 日志应出现「贴吧广告整卡移除 v0.2」。旧缓存卡片可能仍存在，先重新加载页面，不必卸载贴吧。

首页整卡过滤直接编辑服务器返回的数据；帖子/评论广告主要通过关闭广告位、竞价和第三方 SDK 初始化配置来尝试阻止客户端插入。若仍有白块，需要新的复现抓包，不能靠这些配置证明客户端已经改变布局。

## 安装

需要 Loon **3.5.1 (983) 或更新版本**。本插件采用 [Loon 官方新版脚本语法](https://nsloon.app/docs/Script/script_v2/)。

在 Loon 的插件页面添加以下订阅地址：

```text
https://raw.githubusercontent.com/zhuchen458/bdtbads-loon/main/TiebaAds.plugin
```

1. 下载并启用插件；确认两个远程脚本下载成功。
2. 在 Loon 中开启 MitM、生成并安装证书，然后在 iOS「设置 → 通用 → 关于本机 → 证书信任设置」中信任该证书。MitM 用于让 Loon 本地解密并修改 HTTPS 响应。
3. 开启 Loon 的脚本功能，并确认 MitM 域名包含 `tiebac.baidu.com`。
4. 从后台彻底关闭贴吧再重新打开；已缓存的广告可能仍会短暂显示。

脚本不上传抓包、Cookie、账号或浏览记录，不发起额外网络请求。Loon 会从本仓库下载插件和脚本。

## 覆盖范围

| 接口 | 实际处理 |
| --- | --- |
| `/c/f/ad/getSplashAd` | JSON `data` 广告数组置空，保留状态码和其他元数据 |
| `/c/f/ad/getFeedAd` | 验证 Protobuf 成功包后，将外层 field 2 广告数据置为空 message |
| `/c/b/ad/adBid` | 同上，清空独立广告竞价结果 |
| `/c/f/excellent/personalized` | 从 `BannerList` 移除完整 `app`/`pb_banner_ad` 广告卡片；若父容器为空也删除；移除明确 `is_ad=1` 的推荐条目 |
| `/c/f/pb/page?cmd=302001` | 旧版帖子结构的 `BannerList` 同上，保留正常评论；仅合成测试覆盖 |
| `/c/s/sync` | 关闭已识别开屏/广告 SDK 初始化开关，设置首页/吧页/帖子广告 blocked 标记，竞价数量归零，移除对应 SSP 广告位和明确标记为广告的浮动入口 |

二进制处理保留正常内容与未知字段的原始字节。只重新编码发生变动的外层长度，不重建正常帖子，不因正文提到「广告」或「京东」而删帖。错误响应、畸形数据和不符合预期的包会原样放行。

广告请求仍会发送到服务器，本插件在响应阶段清空广告数据；不保证节省下载流量。空广告数据是否会触发客户端其他广告源回退，需要真机验证。

新版帖子 `cmd=309751` 与旧版字段编号含义不同，保留该响应：样本中 `data.field9` 是「热门/正序/倒序」排序菜单，不能当作旧广告字段删除。WebView 及客户端固定布局、未识别 SDK 或缓存仍可能显示占位。不会封禁百度整站、图片 CDN、登录或安全验证域名，也不会修改会员状态。

## 验证与回滚

真机请依次检查：冷启动和切回前台的开屏、首页信息流、帖子页、正常看图/翻页/评论、登录和私信。查看 Loon 日志中的「贴吧开屏与广告配置」「贴吧信息流与竞价广告」是否命中。

若异常，先停用插件，再关闭并重开贴吧。`sync` 配置可能被客户端缓存，需要下一次正常同步恢复；如果此前设置过全局证书信任，停用插件不会自动撤销该设置。

离线验证（Node.js，无第三方依赖）：

```sh
node tests/test.mjs
node tests/test.mjs /path/to/local.har
```
